Bienvenido

Recibir reportes comunitarios de animales encontrados en situación de riesgo, clasificar los avisos por tipo y urgencia, y mostrar una lista de seguimiento que sirva como referencia para la brigada.

Patitas al Rescate se plantea como una herramienta inicial para una brigada barrial que recibe avisos de moradores. A diferencia de un sitio centrado en la presentación de un refugio, este prototipo organiza los reportes como incidencias comunitarias. La portada explica cómo se inicia un reporte y qué información debe aportar la persona que comunica el hallazgo. El formulario solicita un título breve, la categoría del animal, el nivel de urgencia y una descripción del lugar y de su condición. El listado presenta los reportes con un código de seguimiento y una observación de atención.

¿Cómo utilizar el prototipo?

Registrar un caso

Ingrese a la opción «Crear reporte» y complete los campos disponibles con la información conocida del animal.

Consultar información

Acceda a «Consultar registros» para revisar los casos de demostración organizados en una tabla.

Alcance de esta versión

Esta entrega corresponde a una estructura HTML5. No almacena datos en una base de datos ni utiliza hojas de estilo CSS o programación JavaScript.
